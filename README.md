
# CNUqrweb

## Description

CNUqrweb is a QR code generator for Chungnam National University student identification, used in official and library applications.

## Usage

1. Run `app.py` to start the Flask server.
2. Access `http://127.0.0.1:5000/cnuqr/<학번>` to get a QR code image for the student ID.
